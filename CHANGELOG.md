# Changelog

All notable changes to the KDCN Digital Platform will be documented in this file.

## [2.0.0] – 2026-07-24

### Added
- **Public Layer**: Complete homepage, about, services, portfolio, blog, careers, livestream, contact, FAQ, resources, privacy, terms.
- **Commerce Layer**: Store, cart, checkout, success, packages, M-Pesa, Card, Bank Transfer.
- **Client Layer**: Login, register, profile, dashboard, orders, projects, documents, messages.
- **Intelligence Layer**: AI Assistant, Knowledge Base, Customer Support, Sales Automation.
- **Business Layer**: Admin dashboard, analytics, revenue tracking, CRM, workflow automation.
- **Full responsive design** with dark/light theme.
- **GitHub Actions workflow** for static deployment.
