## Overview

The **KDCN Digital Platform** is a complete, enterprise‑grade digital ecosystem built for cybersecurity, IT systems, software development, cloud infrastructure, and business management.

It is designed as a **5‑layer architecture** that serves as the operational backbone for modern digital businesses.

---

## The Five Layers

| Layer | Description |
| :--- | :--- |
| **🌐 Public Layer** | Brand presence, services, portfolio, blog, resources |
| **🛒 Commerce Layer** | Digital store, packages, cart, checkout, payments (M-Pesa, Card, Bank) |
| **🧠 Intelligence Layer** | AI Assistant, Knowledge Base, Customer Support, Sales Automation |
| **👤 Client Layer** | Login, Register, Dashboard, Orders, Projects, Documents, Messages |
| **📊 Business Layer** | Admin Dashboard, Analytics, Revenue Tracking, CRM, Workflow Automation |

## Quick Start

1. Clone the repository:
   ```bash
   git clone git@github.com:Kingman37-net/kdcn-development.git
```

2. Navigate to the public/ folder:
   ```bash
   cd kdcn-development/public
   ```
3. Serve with Live Server:
   ```bash
   live-server --port=8081
   ```
4. Open http://localhost:8081 in your browser.
